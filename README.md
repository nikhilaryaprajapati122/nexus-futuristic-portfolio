## ◉ ABOUT

**NEXUS** is a futuristic web interface designed as a
personal developer portfolio and experimental UI project.

The project combines a dark cyber-inspired visual system
with interactive components, animated interfaces and a
command-line style terminal.

The goal is to experiment with modern frontend design while
building a practical portfolio project.
